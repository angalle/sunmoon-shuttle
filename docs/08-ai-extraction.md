# 08. AI 구조화 추출 계약 (v1) — 시간표 페이지 전용

> 사용자 지시(2026-10-09, 그대로): "**시간표 파서도 json 구조형태로 AI 보고 가져오게 할 수 있지 않아? 어차피 거기는 시간표 페이지라 아예 다른 페이지로 변경되는 건 다른 페이지를 찾아봐야 하는 거지만, 해당 페이지는 시간표 페이지로만 쓰는 곳이라**"

## 1. 전제 — 페이지 종류가 고정이다
- 원본은 **시간표 전용 페이지**다(경로 노선 × 요일 페이지 + 방학 안내 페이지). 성격이 바뀌지 않는다.
- 따라서 **일반 HTML 추출기가 아니라 "선문대 셔틀 시간표" 전용 추출기**를 만든다 — 프롬프트·스키마·검증을 이 도메인에 특화할 수 있다(정확도 상승, 검증 강도 상승).
- **이 계약 밖의 상황**: 페이지가 아예 **다른 종류**(공지 게시판·로그인·새 사이트)로 바뀌면 그건 **페이지 목록 자체를 갱신해야 하는 일**이다(사람 판단). 이 계약은 "같은 종류의 시간표 페이지의 **마크업·열 구성이 바뀐 경우**"를 AI로 흡수하는 것이 목적이다.

## 2. 역할 분담 (Stage A — 지금 채택)
| 주체 | 하는 일 |
|---|---|
| 규칙 파서(`rules.ts`) | **정본(canonical)**. 오늘과 동일하게 표를 읽어 행을 만든다. |
| **AI 표 추출기(신규)** | 페이지 텍스트를 읽고 ① **열 이름 → 의미 키 매핑**(예: `천안아산역 출발` → `depStation`) ② **행 값 초안**(JSON) 을 만든다. |
| **교차검증 게이트(신규)** | 규칙 결과 vs AI 결과를 **행 단위로 비교**한다. |
| 발행기 | **둘 다 일치**할 때만 발행. 불일치·규칙 0건이면 **발행 보류 + 알림**(§6). |

- **AI가 정본을 조용히 덮어쓰지 않는다.** AI 단독 채택은 규칙이 아무것도 못 읽었을 때(§5 Stage B)만, 그리고 아래 검증을 **전부 통과**할 때만.
- AI는 **수치를 만들 수 없다**(§3). 열 매핑과 행 구조만 담당한다.

## 3. 수치 규칙 (환각 차단의 핵심)
- 시각(`08:05`)·분(`15`)·행 수·순번은 **원문에 실제로 존재하는 토큰만** 쓸 수 있다.
- 모든 셀 값은 **원문 부분문자열**이어야 한다(정규화 허용: 앞뒤 공백·전각/반각 공백·`\u00a0` → 일반 공백). 그 외 변형 금지.
- 원문에 없는 값·계산된 값(예: "대략 20분"을 `20`으로 바꿔 넣기)은 **즉시 검증 실패**.
- `null` 은 "원문이 비어 있음"을 뜻하며 **추측으로 채우지 않는다**.

## 4. 검증 4종 (발행 전 기계 판정, 전부 통과해야 함)
1. **셀 앵커**: 모든 셀 값이 그 페이지 텍스트에 존재(§3 정규화 기준).
2. **시각 집합 일치**: 원문에서 뽑은 `HH:MM` 토큰 **집합**과 추출 결과의 시각 **집합**이 **동일**(부분집합·초과 모두 실패). 표에 없는 시각을 만들면 실패, 표의 시각을 빠뜨려도 실패.
3. **행 수 일치**: 추출 행 수 = 원문 표의 `순` 번호 최대값(또는 행 수). 다르면 실패.
4. **스키마**: v3 스키마(타입·필수 필드·enum) 통과.

## 5. 채택 규칙 + 교차검증 등급 (T34 실측 반영 · 2026-10-09)

### 5-1. 비교 전 정규화 (양쪽 동일 함수)
① **병합 셀 전개**(상위 행 값의 하위 상속 구조는 양쪽 동일 규칙으로 전개) ② 공백·전각/반각·`\u00a0` 정규화 ③ **`null` vs `""` 동일 취급**. 시각 표기 변형(`8:5`→`08:05`)은 허용하지 않는다(§3).

### 5-2. 불일치 3등급
| 등급 | 정의 | 판정 |
|---|---|---|
| **① 값 모순** | **같은 의미 키**에 양쪽 다 값이 있는데 다름 | **차단** — 발행 보류 + 알림 |
| **② key-shift** | 같은 **행**에 값은 있으나 **다른 의미 키**로 배정 | **경고** — 발행 진행 · `aiExtract.keyShiftRows` 기록 |
| **③ null-vs-값** | 정규화 후에도 한쪽만 값 | **경고** — `aiExtract.nullMismatchRows` 기록 |
- **Stage A(규칙 정본 발행)**: **①만 차단**. 앱에 나가는 값은 규칙 정본이므로 ②③은 로그만.
- **실측 근거**(T34): 10페이지 중 8페이지 **100% 일치**, 불일치는 **`cheonan-station/weekday` 32/33 · `cheonan-terminal/weekday` 38/38** 에 집중되며 두 페이지 모두 **검증 4종 전부 통과**(원문 시각 80==80 · 67==67, 행 수 33==33 · 38==38) → **값이 아닌 열 배정 차이(②)** 로 분류된다. 이걸 차단으로 처리하면 매 실행 발행이 막힌다.

### 5-3. 채택 규칙
- **Stage A(기본)**: 규칙 결과를 발행. AI 결과는 교차검증 입력이며 `aiExtract.agreedRows`(정규화 후)·`rawDisagreedRows`·①②③ 카운트로 기록.
- **Stage B(규칙 실패 시)**: 규칙이 그 페이지에서 **행 0건**일 때만 AI 초안을 채택 후보로 삼는다. 조건 = §4 전부 통과 + **① 0건 + ② 0건** + ③는 허용. 채택분은 `extractedBy: "ai"` + `needsReview: true` + `adoptedPages[]` 기록. **AI가 정본을 조용히 덮어쓰는 경로는 금지.**
- **Stage C(정본 승격)**: 사용자 승인 후에만.

## 6. 비용 가드 (AI 호출을 늘리지 않는다)
- **페이지 `contentHash` 캐시**: 페이지 내용이 바뀌지 않았으면 **AI 호출 0회**(직전 추출 결과 재사용). → 평소 하루 2회 실행에서 **호출 0~2회**.
- 바뀐 페이지만 호출한다. **실행당 호출 상한 12회**(초과 시 남은 페이지는 규칙 전용 + 로그).
- `temperature: 0` · JSON 출력 강제 · 프롬프트 템플릿 해시 기록(기존 `promptTemplateSha256` 과 동일 방식).

## 7. 드리프트 게이트 (같이 넣는다)
발행 전, **직전 발행본**과 비교해 아래 중 하나라도 걸리면 **발행 보류 + 워크플로 실패(알림)**:
| 신호 | 임계 |
|---|---|
| 전체 편 수 변동 | **±10% 이상** (사용자 지시 2026-10-09) |
| 노선 소실 | 기존 `routes[].id` 중 사라진 것 **≥1** |
| 시각 0건 | 특정 경로×요일의 편 수가 **0** 인데 직전엔 >0 |
| 요일 버킷 소실 | `byDay` 키가 줄어듦 |
| 열 구성 변경 | 열 의미 키(`keys`) 집합이 달라짐 |
- 보류 시 **원본 스냅샷 + AI 초안 + 비교 표를 아티팩트로 첨부**한다(사람이 5분 안에 판단할 수 있게).
- **사람이 명시 승인하는 탈출구**: `--force-publish` 로 실행하면 보류를 해제하고 발행하되, `aiExtract.drift = {blocked: true, forced: true, reasons:[…]}` 로 **강제 발행 사실을 데이터에 남긴다**(조용한 우회 금지). 알림은 그대로 남는다.
- 임계 근거: 10% 는 민감하게 잡은 값이라 **정상 개편(예: 학기 개편으로 노선 증감)에서도 걸릴 수 있다** — 그때는 `--force-publish` 로 승인 발행하고, 반복적으로 걸리면 임계를 재조정한다.

## 9. 수용 기준 (AC-AI1)
- **AC-AI1-1** **환각 주입 실패**: 표에 없는 시각·행을 추가한 AI 응답을 주입하면 **검증 4종에서 실패**하고 **발행되지 않는다**(exit 1·산출물 0건) — 모의서버 테스트.
- **AC-AI1-2** **시각 집합 일치**: 정상 응답에서 원문 `HH:MM` 집합 = 추출 집합(수치 제출) · 행 수 = 원문 행 수.
- **AC-AI1-3** **해시 캐시**: 페이지 내용이 같으면 **AI 호출 0회**(`calls: 0` 실측) · 바뀐 페이지만 호출 · 상한 12 준수.
- **AC-AI1-4** **교차검증**: 규칙 결과와 AI 결과가 같은 페이지에서 **행 단위 일치 수치**(agreedRows) 제출 · 불일치를 인위적으로 만들면 **발행 보류 + 사유 로그**.
- **AC-AI1-5** **Stage B**: 규칙이 0건인 페이지에서 AI 초안이 §4를 통과하면 `extractedBy: "ai"`·`needsReview: true` 로 채택되고 로그에 남는다(모의 테스트).
- **AC-AI1-6** **드리프트 게이트**: 직전 발행본 대비 편수 -40% 를 인위적으로 만들면 **발행 보류 + 알림 사유 기록**(아티팩트 생성).
- **AC-AI1-7** **회귀**: 기존 발행본과 **동일한 결과**(규칙 정본 유지) · `npm run test` 0 fail · `--no-ai` 폴백 동작 · 실 DeepSeek 1회 실행 exit 0(토큰·호출 수 기록).
