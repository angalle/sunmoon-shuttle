# 모바일 UX 설계 — 앱 셸·스플래시·화면 분리 (v1)

> 작성: ProjectCreator(총괄) · 2026-10-06 · 상태: **승인된 설계(구현 대기)**
> 사용자 지적: "모바일앱처럼 스플래시도 있고 그래야지… 모바일 UI 느낌이 하나도 없고 그냥 다 박아놨네"
> 이 문서가 **화면 계약**이다. 구현은 이 문서를 기준으로 하고, 어긋나면 문서를 먼저 고친다.

## 0. 문제 정의 (현행 진단)

- 홈에 **모든 것을 한 화면에 쌓았다**: 상태줄 → 공지 배너 → 다음 출발 카드 → 방향 필터 칩 → 남은 출발 목록 → 접힘 안내(출처·이용안내·방학·다가오는 변동). **스크롤 한 줄로 다 밀어 넣은 느낌**이고, 웹 페이지지 앱이 아니다.
- **진입 경험이 없다**: 앱을 열면 곧바로 텍스트가 뜬다(스플래시·로딩 상태 없음). 캐시가 없을 때 빈 화면/스피너도 없다.
- **화면 전환 개념이 없다**: "지금 탈 수 있는 것"과 "전체 시간표"가 같은 뷰에 섞여 있다.
- 터치·간격·safe-area 는 개별 처리는 되어 있으나 **앱 셸(앱바/탭바) 규격이 없다**.

## 1. 목표 (사용자가 체감하는 것)

1. 앱을 열면 **스플래시**(로고 + 진행 표시)가 잠깐 뜨고, 데이터가 준비되면 **부드럽게** 본문으로 바뀐다.
2. **"지금"과 "전체"가 화면으로 분리**된다 → 하단 탭 2개.
3. 모든 화면이 **모바일 앱의 규격**(앱바·카드 스택·48px 터치·safe-area·스켈레톤)을 따른다.
4. 오프라인·캐시 폴백·판정(tripStatus) 등 **기존 계약은 그대로** 유지된다(회귀 0).

## 2. 앱 셸 구조 (계약)

```
┌──────────────────────────────────────┐
│ (safe-area top)                      │
│  앱바:  선문대 셔틀        [새로고침] │  ← 제목 + 오늘 날짜/시각(작게)
├──────────────────────────────────────┤
│  본문 스크롤 영역 (탭에 따라 내용)   │
│                                      │
│   [지금] 뷰  또는  [전체] 뷰         │
│                                      │
├──────────────────────────────────────┤
│  탭바:   ● 지금        ○ 전체         │  ← 48px 터치, safe-area bottom
└──────────────────────────────────────┘
```

- **앱바**: 제목 `선문대 셔틀` + 보조줄(오늘 날짜·시각, KST) + **새로고침 버튼**(수동 갱신, 스피너 표시)
- **탭바**: `지금` / `전체` 2개. 탭 전환은 상태 저장(마지막 탭 유지) · 키보드/스크린리더 `role="tablist"`/`tab`/`tabpanel` 규격 준수
- **스크롤**: 본문만 스크롤(앱바·탭바 고정) · `overscroll-behavior: contain`
- **safe-area**: `env(safe-area-inset-*)` 를 앱바·탭바·본문 패딩에 반영(iPhone 노치·홈인디케이터)

## 3. 스플래시 (진입 경험)

- **표시 조건**: 앱 시작 시 **항상** 표시(웹·PWA), 데이터가 준비되면 사라진다.
- **내용**: 앱 아이콘/로고 + 앱 이름 + 진행 표시(스피너 또는 진행 바) + 문구 `시간표 불러오는 중`
- **지속 시간**: 최소 400ms(깜빡임 방지) · **최대 2.5s**(초과 시 스켈레톤/캐시 폴백으로 넘어간다 — 스플래시에 갇히면 안 된다)
- **전환**: 200ms 페이드아웃(opacity) — `prefers-reduced-motion: reduce` 면 즉시
- **접근성**: `role="status"` + `aria-live="polite"` 로 "불러오는 중"을 알린다 · 포커스는 본문 첫 요소로 이동
- **재방문**: 스플래시는 **매 실행 표시**(백그라운드 복귀 시엔 표시하지 않음 — `visibilitychange` 로 구분)
- **네이티브(Capacitor)**: 앱 시작 스플래시(`@capacitor/splash-screen` 또는 수동 구현) + 웹 스플래시가 **이어지도록** 색·로고를 동일하게 맞춘다(두 번 깜빡이지 않게)

## 4. 화면별 내용 (정보 위계 — "다 박아놓기" 해소)

### 4-1. [지금] 뷰 (기본 탭)
1. **히어로 카드 1장**: 다음 출발 1편 — 노선·시각·도착·남은 시간(**도메인 값**)·사유 배지
2. **지금 탈 수 있는 편 3~5편** (오늘 운행 편만 — `tripStatus.runs`)
3. **오늘 안내 배너**(있을 때만): 운행 없음 / 대체 시간표 / 방학 — 최대 1개(우선순위: 운행없음 > 대체 > 방학)
4. **바로가기 카드 2개**: `전체 시간표 보기` · `이용 안내`(접힘 대신 **별도 시트/화면**으로 이동)
- 지금 뷰에는 **출처·고지·정차창·다가오는 변동을 넣지 않는다**(전체/안내로 이동)

### 4-2. [전체] 뷰
1. **요일 탭**(평일/토/일) + **방향 필터 칩**(전체/학교에서 출발/학교로 도착)
2. **전체 편 목록**(가상 스크롤은 불필요 — 165행 수준) + 각 행 사유 배지·`약 N분 소요`
3. **다가오는 운행 변동**(14일 내, 최대 2줄)
4. 하단: 출처 1줄(`학교 안내 페이지`) + `데이터 갱신: <시각>`

### 4-3. 이용 안내(시트/서브화면)
- 정차창(`stopWindows`) · 요금·지연 안내 · 방학 시간표 링크(기간이 있을 때만) · 앱 고지(비공식)

## 5. 모바일 감각 규격 (토큰)

| 항목 | 값 |
|---|---|
| 터치 타깃 | ≥48×48px (탭바·칩·버튼) |
| 간격 | 4/8/12/16/24 스케일 · 카드 간 12px |
| 카드 | radius 16px · 얇은 테두리(1px, `--color-border`) · 과한 그림자 금지(라이트 톤 유지) |
| 본문 좌우 패딩 | 16px (+ safe-area) |
| 앱바 높이 | 56px (+ safe-area top) |
| 탭바 높이 | 56px (+ safe-area bottom) |
| 폰트 | 시스템 폰트 스택(오프라인 · 외부 CDN 금지) · 본문 16px / 보조 14px / 캡션 12px |
| 로딩 | **스켈레톤 카드 3장**(빈 화면·텍스트만 금지) |
| 전환 | 탭 전환 150~200ms 페이드/슬라이드 · `prefers-reduced-motion` 존중 |
| 다크모드 | 기존 토큰 유지(`prefers-color-scheme`) |

## 6. 하지 말 것 (금지)

- 유료 UI 킷·템플릿·외부 폰트/아이콘 CDN(오프라인 원칙 위반)
- 스플래시를 **광고/브랜딩 놀이터**로 만들지 않는다(2.5s 상한, 스킵 불가라도 짧게)
- 과한 애니메이션(바운스·패럴랙스)·소리·진동
- 기존 계약 위반: 화면 `원본` 0회 · 학교 링크 ≤1개 · `needsReview` 미노출 · 판정 로직은 도메인(`tripStatus`)만

## 7. 수용 기준 (AC — 증거로만 판정)

- **AC-U1** 첫 진입 스크린샷: **스플래시**(로고+`시간표 불러오는 중`) → 본문 전환. 2.5s 상한·400ms 하한 실측(시간 로그)
- **AC-U2** 탭 2개(`지금`/`전체`) 존재 · `role=tablist/tab/tabpanel` · 키보드 이동 · **마지막 탭 유지**(재실행 후)
- **AC-U3** `지금` 뷰·`전체` 뷰 스크린샷 각 1장 + **390×844(iPhone)** 과 **360×800(Android)** 두 크기에서 레이아웃 깨짐 0(가로 스크롤 0)
- **AC-U4** safe-area: 노치 시뮬레이션(iPhone)에서 앱바·탭바가 잘리지 않음(스크린샷)
- **AC-U5** 로딩 중 **스켈레톤** 표시(캐시 없는 첫 실행 주입) 스크린샷 · 스플래시에 갇히지 않음(2.5s 후 진행)
- **AC-U6** `prefers-reduced-motion: reduce` 에서 전환 애니메이션 0(실측)
- **AC-U7** 회귀: `npm run test` 0 fail · `verify:offline` PASS · `v1_smoke`/`v2_smoke`/`a11y` PASS(항목 수 유지) · `lint:boundary` PASS · 화면 `원본` 0회 · 학교 링크 ≤1
- **AC-U8** 네이티브(Capacitor) 빌드가 스플래시 색·로고를 웹과 동일하게 사용(코드/에셋 대조)

## 9. 개정 — "그냥 시간표" 우선 (2026-10-06, 사용자 지시)

> 사용자 지시(그대로): "이상한 텍스트 보여주지말고 그냥 버스스케줄표 보여주고 상단 푸터는 고정되서 현재시간 날짜보여주고 알맞는 시간표 쪽으로 스크롤되서 표기만 살짝해주면되잖아"

### 9-1. 화면의 주인공은 **시간표**다
- 본문은 **시간표 목록 하나**로 구성한다(히어로 카드·설명 블록·문구 나열 없음).
- **탭 분리(지금/전체)를 없앤다** — 화면 하나에서 시간표를 보여주고, **필요한 위치로 자동 스크롤**한다.
- 페이지 상단에 붙던 잡다한 블록(소개문구·다가오는 운행 변동·데이터 갱신 줄·출처 고지·요금/지연 안내·방학 배너 문구)은 **본문에서 제거**하고, **정보 시트(ⓘ 버튼)** 로 옮긴다.

### 9-2. 고정 상단 바 (스크롤해도 고정)
- **현재 날짜·시각**을 크게: `10월 6일 (화) · 14:23` — **분 단위로 갱신**(1초 타이머로 분이 바뀔 때만 다시 그린다).
- 오늘 요일 버킷(평일/토/일) 표시는 **요일 전환 컨트롤**로 유지(시간표 자체의 축).
- 우측: **ⓘ(정보 시트)** · (선택) 새로고침.
- 앱 이름/로고는 넣지 않는다(스플래시에서 이미 보여줬다).

### 9-3. 자동 스크롤 + 살짝 표시 (핵심)
- 화면 진입 시(그리고 요일 탭 전환·새로고침 후) **지금 시각 기준 "다음 출발" 행으로 자동 스크롤**한다. 목표 위치는 **고정 상단 바 바로 아래**(가려지지 않게 `scroll-margin-top` = 상단 바 높이).
- 그 행만 **살짝 강조**: 좌측 3px 액센트 라인 + 배경 톤 한 단계(`--color-highlight`). **배지·문구·테두리 박스 금지.**
- 지금 시각보다 **이미 지나간 행은 흐리게(dim)** 처리하고, **오늘 운행하지 않는 편은 한 단계 더 흐리게 + 우측에 짧은 토큰 하나**(예: `금 휴`)만 둔다. 긴 사유 문구 금지.
- 자동 스크롤은 **애니메이션 없이(instant)** 또는 `prefers-reduced-motion` 존중. 사용자가 직접 스크롤한 뒤에는 **재진입/전환 시에만** 다시 맞춘다(주기적 재스크롤 금지 — 스크롤 방해).

### 9-4. 그래도 남겨야 하는 최소 1줄 (예외)
- **오늘 운행이 아예 없을 때**: `오늘은 운행이 없습니다 · 다음 운행: 10월 8일 (목) 08:00` — 스크롤 대상이 없으므로 필요하다.
- **대체 시간표**(예: 개천절대체휴일 → 일요일 시간표): 상단 바 아래 **얇은 1줄**만.
- **방학 기간**: 상단 바 아래 얇은 1줄만(기간이 있을 때만).
- 위 3가지는 **동시에 최대 1줄**(우선순위: 운행없음 > 대체 > 방학).

### 9-5. 정보 시트(ⓘ)로 옮기는 것 (본문에서 제거)
출처(학교 안내 페이지 링크 1개) · `데이터 갱신: <시각>` · 요금/지연 안내 · 정차창(`stopWindows`) · 방학 시간표 링크 · 비공식 앱 고지 · 미해석 경고(내부) · 개인정보처리방침 링크.

### 9-6. 유지되는 계약 (변경 금지)
`tripStatus` 판정(도메인) · 화면 텍스트 `원본` 0회 · 학교 링크 ≤1개(시트 안) · `needsReview`/`unknownNote` 미노출 · 스플래시(진입) · 오프라인 캐시 폴백 · 496 테스트·스모크 8종 유지.

### 9-7. 수용 기준 (AC-U9)
- **AC-U9-1** 화면 진입 시 **다음 출발 행이 보이는 상태**로 스크롤됨(스크린샷 + 스크롤 오프셋 수치) · 상단 바에 **현재 날짜·시각** 표시(분 단위 갱신 실측)
- **AC-U9-2** 본문에 **히어로 카드·설명 블록·배지 나열 없음**: 화면 텍스트에서 제거 대상 문구(소개문구·`데이터 갱신`·`출처·고지`·요금 안내) 0건(실측 카운트)
- **AC-U9-3** 강조는 **좌측 라인 + 배경 톤**만(테두리/배지 0개) · 지나간 행 dim · 오늘 미운행 편은 dim + 토큰 1개 이하
- **AC-U9-4** 자동 스크롤이 **가려짐 없이** 동작(`scroll-margin-top` 적용, 행 y좌표 ≥ 상단 바 하단) · 사용자가 스크롤한 뒤 3초간 재스크롤 없음(실측)
- **AC-U9-5** 회귀: `test` 0 fail · 스모크 8종 PASS(특히 `t22_smoke` 금요일 55편/월요일 115편 · `t24_smoke` 스플래시) · `build` PASS

## 10. 개정 — 이동 버튼 + 폰트 미세 축소 (2026-10-06, 사용자 지시)

> 사용자 지시(그대로): "맨위로, 현재시간으로 버튼 만들어주고 좀더 폰트약간더 작게해줘"

### 10-1. 이동 버튼 2개 (우하단 플로팅)
- **`현재 시간으로`** — 누르면 **지금 시각 기준 다음 출발 행**으로 즉시 이동(§9-3 의 자동 스크롤과 동일 로직 재사용). 사용자가 스크롤해서 억제된 상태여도 **버튼은 항상 동작**한다(억제 해제).
- **`맨 위로`** — 누르면 목록 맨 위로 즉시 이동.
- **배치·규격**: 우하단에 **세로 스택 2개**, 지름/높이 **48px 이상**(터치 규격) · **safe-area bottom + 16px** 만큼 띄운다 · 반투명 배경 + 얇은 테두리(라이트 톤 유지) · 아이콘(↑ / ⟳또는 시계) + `aria-label`(`맨 위로`, `현재 시간으로`) · 키보드 포커스 가능.
- **겹침 금지**: 마지막 행·탭바·시트와 겹치지 않게 본문 하단 패딩을 버튼 높이만큼 확보.
- **동작 규칙**: 이동은 `prefers-reduced-motion: reduce` 면 즉시(애니메이션 0), 아니면 150~200ms.
- 버튼은 **문구를 화면에 길게 쓰지 않는다** — 아이콘 + 스크린리더 라벨. (툴팁/라벨 텍스트 노출 최소)

### 10-2. 폰트 미세 축소 (한 단계)
| 위치 | 현재 | 변경 |
|---|---|---|
| 시간표 행 시각(주 정보) | 16px | **15px** |
| 행 보조(도착·소요시간) | 14px | **13px** |
| 조건 토큰·캡션 | 12px | **11px** |
| 상단 바 날짜·시각 | 16px | **15px** |
- **하한 11px** — 더 줄이지 않는다(가독성·접근성).
- **행 높이·터치 타깃은 줄이지 않는다**(48px 유지). 시각 열 정렬을 유지해 시간표 스캔이 쉬워야 한다.
- **대비는 4.5:1 이상 유지**(폰트 축소로 대비 기준을 낮추지 않는다).

### 10-3. 수용 기준 (AC-U10)
- **AC-U10-1** `현재 시간으로` 클릭 → 다음 출발 행이 **상단 바 아래**로 이동(클릭 전/후 `scrollTop` 수치 + 행 y좌표) · **사용자 스크롤로 억제된 상태에서도 동작**(억제 해제 실측)
- **AC-U10-2** `맨 위로` 클릭 → `scrollTop = 0`(수치)
- **AC-U10-3** 두 버튼 **터치 타깃 ≥48px**(실측) · `aria-label` 존재 · 키보드 포커스 가능 · **safe-area 반영**(하단 여백 수치) · 본문 마지막 행과 겹침 0(실측)
- **AC-U10-4** 폰트 실측 표: 행 시각 15px · 보조 13px · 캡션/토큰 11px · 상단 바 15px (**11px 하한 위반 0**) · 대비 ≥4.5:1 유지 · 행 높이 불변
- **AC-U10-5** 회귀: `test` 0 fail · 스모크 8종 PASS 유지(`t24_smoke`/T27 검사 포함) · `build`·`lint:boundary` PASS · 화면 `원본` 0회 · 스크롤 자동 억제(사용자 스크롤 후 3초) 규칙 유지

## 11. 개정 — 상단 고정 필터 + "오늘 아님" 안내 (2026-10-06, 사용자 지시)

> 사용자 지시(그대로): "토요일 일요일 전체 학교도착 터미널 도착 도 **상단에 붙여줘**. 그리고 **오늘 아닐 날짜에** 지금시간으로 가는 버튼 누르면 **적절한 메세지** 던져줘"

### 11-1. 상단 고정 영역(스티키) 구성
스크롤해도 **고정되는 영역**에 아래 3줄을 모두 넣는다(§9-2 확장):

```
┌──────────────────────────────────────────┐
│ 10월 6일 (화) · 14:23            [ⓘ]     │ ← 1줄: 현재 날짜·시각(15px) + 정보 시트
│ [평일] [토요일] [일요일]                  │ ← 2줄: 요일 전환(3개, 선택 상태 명확)
│ [전체] [학교 도착] [터미널 도착]           │ ← 3줄: 방향 필터(3개)
└──────────────────────────────────────────┘
```
- **라벨은 위 문자열 그대로**: `평일`/`토요일`/`일요일` · `전체`/`학교 도착`/`터미널 도착`
- **필터 의미**: `전체` = 모든 편 · `학교 도착` = **학교로 도착하는 편** · `터미널 도착` = **터미널(천안터미널·온양터미널)로 도착하는 편** (데이터의 도착 열 기준). 각 칩에 **해당 편수**를 함께 표기(`전체 115`) — 0건이면 흐리게 + 0 표기(빈 결과를 숨기지 않는다).
- **터치 타깃 ≥48px**(칩 높이 48px, 가로 스크롤 허용 — 3개가 한 줄에 안 들어가면 **가로 스크롤 칩 행**으로, 줄바꿈으로 높이 늘리지 않는다)
- 선택 상태는 **배경 톤 + 굵기**로(색만으로 전달 금지 — 대비 4.5:1 유지)
- **고정 영역 전체 높이가 곧 자동 스크롤 오프셋**이다: `scroll-margin-top` = 상단 고정 영역 실제 높이로 **동적 계산**(하드코딩 금지). 요일·필터 변경 시에도 다음 출발 행이 **가려지지 않아야** 한다.
- 요일/필터 상태는 **저장**한다(재실행 시 유지).

### 11-2. `현재 시간으로` 버튼 — "오늘 아님" 안내
버튼은 **선택된 요일 버킷이 오늘 요일과 다를 때** 그냥 스크롤하지 말고 **안내를 띄운다**:
| 상황 | 메시지(토스트, 하단 3초) | 액션 |
|---|---|---|
| 선택 요일 ≠ 오늘 요일 | `오늘은 <오늘요일>이 아닙니다 · 오늘(<오늘요일>) 시간표로 이동할까요?` | **`오늘 보기`** 버튼 → 오늘 버킷으로 전환 + 다음 출발 행으로 스크롤 |
| 선택 = 오늘 & 남은 편 있음 | (안내 없음) 다음 출발 행으로 이동 | — |
| 선택 = 오늘 & 남은 편 없음(막차 이후) | `오늘 남은 편이 없습니다 · 다음 운행: <날짜(요일)> <시각>` | 없음(수동 닫기) |
| 선택 요일 & 해당 편 0건(예 토·일 노선 0) | `오늘 시간표에 해당하는 편이 없습니다` | **`오늘 보기`**(오늘이 다른 요일일 때) |
- 토스트 규격: 하단(이동 버튼 위), 반투명 배경, **문구는 1줄**(길면 말줄임), `role="status"` + `aria-live="polite"`, **자동 3초 후 사라짐**, 탭하면 즉시 닫힘.
- 토스트가 **이동 버튼을 가리지 않는다**(버튼 스택 위쪽에 배치).

### 11-3. 수용 기준 (AC-U11)
- **AC-U11-1** 상단 고정 영역에 **3줄**(날짜·시각 / 요일 3개 / 필터 3개)이 있고 **스크롤 중에도 고정**(스크롤 전후 좌표 동일 실측)
- **AC-U11-2** 칩 라벨이 정확히 `전체`·`학교 도착`·`터미널 도착`(화면 텍스트 실측) · 칩 높이 **≥48px** · 각 칩 **편수 표기** · 선택 상태가 배경 톤+굵기(대비 4.5:1)
- **AC-U11-3** 필터 동작: `전체` 편수 = 기존 목록 편수 · `학교 도착`/`터미널 도착` 편수가 **데이터 대조와 일치**(수치 제출) · 토·일에서도 동작
- **AC-U11-4** 자동 스크롤이 **고정 영역 높이를 반영**: 요일/필터를 바꾼 뒤에도 다음 출발 행 y ≥ 고정 영역 하단(가려짐 0, 수치)
- **AC-U11-5** **오늘 아님 상태에서 `현재 시간으로`** → **토스트 문구 표시**(스크린샷 + 텍스트 실측) · **`오늘 보기`** 누르면 오늘 버킷 전환 + 다음 출발로 스크롤(수치) · **토스트 3초 후 사라짐** 실측 · 이동 버튼과 겹침 0
- **AC-U11-6** 회귀: `test` 0 fail · **스모크 8종 PASS**(T27·T28 검사 포함: 자동 스크롤·강조 라인+톤·이동 버튼·폰트 15/13/11) · `build`·`lint:boundary` PASS · 화면 `원본` 0회

## 12. 개정 — 탭·칩 UI 정리 (텍스트 축소·배치) (2026-10-06, 사용자 지시)

> 사용자 지시(그대로): "**탭부분 Ui좀 개선해 텍스트좀 배치도잘하고 텍스트좀 줄여주고**"

### 12-1. 현재 문제 (실측 근거)
- 요일 탭 라벨이 `평일 (오늘)노선 4/5개` 처럼 **괄호·부가 텍스트가 붙어 지저분**하고, `노선 4/5개` 는 **무엇을 뜻하는지 알 수 없음**
- 방향 칩이 `전체 115편`·`학교 도착 24편`·`터미널 도착 91편` 으로 **`편` 접미사가 반복**되어 칩이 길어짐(81·102·112px)
- 두 줄의 **좌우 여백·간격·정렬이 제각각**(앱바 12px·요일 줄 61px·필터 줄 48px 높이 불일치)

### 12-2. 요일 탭 — 등폭 세그먼트 컨트롤
```
┌───────────┬───────────┬───────────┐
│   평일 •  │   토요일   │   일요일   │   ← 등폭 3분할(전체 폭), 높이 44px
└───────────┴───────────┴───────────┘
```
- 라벨은 **`평일` · `토요일` · `일요일`** 만. **`(오늘)`, `노선 N/M개` 텍스트 전부 제거**.
- **오늘 표시는 작은 점(•, 지름 4px)만** 탭 라벨 오른쪽 4px 간격에 — 텍스트로 "오늘"을 쓰지 않는다.
- 선택 상태: **배경 톤 + 굵기 600 + 하단 2px 라인**(색만으로 전달 금지, 대비 4.5:1 유지).
- 3분할 등폭이라 좌우 정렬이 자동으로 맞는다. **줄 전체가 하나의 컨트롤**처럼 보이게 둥근 배경 1개 위에 얹는다(개별 알약 금지).

### 12-3. 방향 칩 — 라벨만 남기고 편수는 작은 숫자로
```
[ 전체 ¹¹⁵ ]  [ 학교 도착 ²⁴ ]  [ 터미널 도착 ⁹¹ ]   ← 높이 40px, 패딩 12px, 간격 8px
```
- 라벨은 **`전체` · `학교 도착` · `터미널 도착`** 유지(의미 유지) · **`편` 접미사 제거**
- 편수는 **라벨 오른쪽에 11px·보조색 작은 숫자**로(`전체 115`) — 라벨(13px)보다 작고 가볍게. **괄호·`편`·`개` 금지**
- 칩 **높이 40px**(세로 중앙 정렬) · 좌우 패딩 12px · 간격 8px · 넘치면 **가로 스크롤**(줄바꿈 금지) · 칩 폭은 내용에 맞춤(등폭 아님)
- 선택 상태: 배경 톤 + 굵기 600 · 0건 칩은 흐리게 + 숫자 `0`
- **칩 행 좌우 여백 = 앱바 좌우 여백과 동일**(12px) — 3줄이 같은 축에 정렬된다

### 12-4. 3줄 공통 정렬 규칙
- 좌우 여백 **12px 동일** · 줄 간격 **4px** · 각 줄 높이: 앱바 57px / 요일 44px / 필터 40px → **고정 영역 총 높이 ≈ 153px**(자동 스크롤 오프셋은 §11-1 대로 **겹침분만** 동적 계산)
- 텍스트는 **세로 중앙 정렬**(`align-items:center`) · 말줄임(`text-overflow: ellipsis`) · **`(`·`)` 같은 부호로 상태를 전달하지 않는다**

### 12-5. 수용 기준 (AC-U12)
- **AC-U12-1** 요일 탭 라벨에 **`노선`·`개`·`(`·`)`·`오늘` 문자열 0건**(화면 텍스트 실측) · 오늘 표시는 **점 요소 1개**(`aria-label="오늘"` 허용, 화면 텍스트 아님) · 탭 3개 **등폭**(폭 차이 ≤1px 실측) · 높이 44px
- **AC-U12-2** 칩 화면 텍스트가 **`전체 115`·`학교 도착 24`·`터미널 도착 91`** 형식(`편`·`개`·괄호 0건) · 편수 글자 크기 **11px < 라벨 13px** · 칩 높이 40px · 간격 8px · 초과 시 가로 스크롤
- **AC-U12-3** 3줄 좌우 여백이 **모두 12px**(실측) · 세로 중앙 정렬 · 고정 영역 총 높이 ≈153px(±8px) · 가로 스크롤 0(390×844·360×800)
- **AC-U12-4** 자동 스크롤 가려짐 **0** 유지(요일·필터 변경 후 다음 출발 행 y ≥ 고정 영역 하단) · 터치 타깃 탭 44px·칩 40px 유지(가로 ≥48px)
- **AC-U12-5** 회귀: `test` 0 fail · **스모크 8종 PASS**(T27 자동 스크롤·강조 / T28 이동 버튼·폰트 / T29 고정 3줄·편수 대조·토스트 검사 유지 — **편수 대조 수치는 그대로**, 표기 형식만 변경) · `build`·`lint:boundary` PASS · 화면 `원본` 0회

## 15. 개정 — 칩 정리 · "오늘로 이동" · 여백 축소 (2026-10-09, 사용자 지시)

> 사용자 지시(그대로): "**전체라는 탭은 없애주고**, 지금시간으로 가는 버튼 누르면 오늘이 아닐 때 툴팁 같은 게 나오는데 **그냥 '오늘로 이동합니다' 하고 오늘 해당 시간으로 이동하게** 해줘. 그리고 **UI 좀 더 간결하고 공백 넓지 않게** 해줘"

### 15-1. `전체` 칩 제거 — 칩은 2개, 토글 방식
- 방향 칩은 **`학교 도착` · `터미널 도착`** 2개만 둔다. **`전체` 칩은 삭제**한다.
- **기본 상태 = 필터 없음(= 전체 표시)** — 선택된 칩이 없는 상태가 곧 "전체"다.
- 칩은 **토글**: 누르면 그 방향만 표시(`aria-pressed="true"`), **다시 누르면 해제**되어 전체로 돌아온다.
- 칩의 편수 숫자는 유지(`${'학교 도착 24'} · ${'터미널 도착 91'}` 형식, §12-3 그대로).
- 필터로 **화면이 빈 경우**(예: 오늘 편이 그 방향에 0편)에는 목록 대신 **얇은 1줄**(§9-4 예외 규칙과 동일 톤)로 안내하고, **필터를 자동 해제하지 않는다**.

### 15-2. `현재 시간으로` 버튼 — 오늘이 아니면 **묻지 않고 이동**
- 버튼을 눌렀을 때 **선택 요일 ≠ 오늘**이면:
 ① **오늘 요일 버킷으로 즉시 전환** ② **오늘의 현재 시각 기준 다음 출발 행으로 스크롤**(§9-3 로직 재사용) ③ **짧은 안내 `오늘로 이동합니다`** 를 1.5초간 표시(토스트, **액션 버튼 없음** — 예전 `오늘 보기` 확인형 제거).
- **오늘이고 남은 편이 있으면**: 안내 없이 그대로 이동(변경 없음).
- **오늘이고 남은 편이 없으면(막차 이후)**: 기존대로 1줄 안내 `오늘 남은 편이 없습니다 · 다음 운행: <날짜(요일)> <시각>` 유지(이건 정보이므로 남긴다).
- 즉 **되묻는 UI를 없애고 "알려주고 바로 실행"** 으로 바꾼다.

## 16. 개정 — "전체" 개념 삭제 · 방향은 항상 하나만 (2026-10-09, 사용자 지시)

### 16-1. 배경 (총괄 실측)

### 16-2. 규칙 — **방향은 항상 하나** (택1)
- 칩은 **택1 세그먼트**다: **`학교 도착` · `터미널 도착`** 중 **항상 정확히 1개가 선택**되어 있다(선택 해제 불가 · "전체" 상태 없음).

- 선택 상태는 저장한다(재실행 시 유지).
- 필터 결과가 0편이면 **얇은 1줄**(`선택한 방향의 편이 없습니다`) + **다른 방향으로 가는 안내 1줄**(`학교 도착 편 보기` 같은 **짧은 전환 수단**)을 둔다 — 이때도 자동 전환은 하지 않는다.

## 17. 개정 — Android 앱: 화면은 앱 안, 데이터는 GitHub Pages 에서 (2026-11-08, 사용자 결정 B)

> 사용자: "안드로이드 앱은 어떻게 설계될거야? 깃허브 페이지 웹뷰로 보여줄거임?" → 선택지 A(Pages 웹뷰)·B·C(현행) 중 **B**.

### 17-1. 문제 (현행 C)
- Capacitor 가 `dist/` 를 APK 안에 넣고, 앱은 상대 경로 `./data/timetable.json` 을 읽는다 → **앱 안의 빌드 시점 사본**.
- 그래서 시간표·학사일정이 Actions 로 매일 갱신돼도 **AAB 재빌드·스토어 업데이트 전까지 앱은 옛 데이터**였다.

### 17-2. 설계 (B)
| 항목 | 웹(Pages) | Android 앱 |
|---|---|---|
| 화면(번들) | Pages | **앱 안**(오프라인 즉시 표시 · 스토어 심사에 유리) |
| 데이터 1순위 | `./data/timetable.json`(같은 출처) | **`https://angalle.github.io/sunmoon-shuttle/data/timetable.json`**(`REMOTE_TIMETABLE_URL`) |
| 실패 시 | 마지막 캐시(IndexedDB) | 마지막 캐시 → **앱 안 사본**(`./data/timetable.json`) → 오류 배너 |
| Service Worker | 사용 | **사용 안 함**(화면은 이미 앱 안) |
| 갱신 시점 | 진입 · 화면 복귀(30분 이상 지났을 때) | 같음 |

- 판별: Capacitor 가 주입하는 `window.Capacitor.isNativePlatform()`(런타임 의존성 추가 없음 — `app/platform.ts`).
- Pages 는 `access-control-allow-origin: *` 로 응답한다(실측) → 앱 출처 `https://localhost` 에서 그대로 받는다.
- 앱 안 사본으로 물러서면 "마지막으로 받은 데이터" 로 표시하고, 나이는 사본의 발행 시각(`fetchedAt`) 기준이다(24h 초과면 `cache-expired`).
- 오프라인 안내에는 기술 오류(주소·예외 문구)를 쓰지 않는다 — 콘솔에만 남긴다.
- **UI 를 바꾸면 여전히 AAB 재빌드가 필요하다.** 데이터(시간표·학사일정)만 재빌드 없이 최신이 된다.
