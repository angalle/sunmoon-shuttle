# 09. 시간표 UI 리프레시 계획 (2026-10-12)

> 사용자 요청(그대로): "**시간표 UI가 좀 투박한거같아 개선계획좀 세워줄수있어? 너무 딱딱하지 않았으면 좋겠고 그렇다고 너무 튀지도 않았으면 좋겠어. 색배합은 선문대로고를 분석해서 어떻게 할지 계획이나 디자인 시안을 보고해봐**"

## 1. 브랜드 색 분석 (선문대 로고·사이트)

| 출처 | 값 | 근거 |
|---|---|---|
| 선문대 사이드(학사 안내) DOM 실측 | **`rgb(0, 52, 127)` = `#00347F`** — 최다 사용 브랜드 색(37회) | `lily.sunmoon.ac.kr` 계산 스타일 전수 집계 |
| 로고 파일 | `https://lily.sunmoon.ac.kr/images2/main/50th_logo_2.png` (280×82) | 헤더 로고(`alt="선문대학교1"`) |
| 보조 중성색 | `#DDDBD9`(따뜻한 회색) · `#555` · `#424242` | 사이트에서 널리 쓰이는 회색 계열 |

- **결론: 브랜드 앵커 = 선문대 네이비 `#00347F`.** 현재 앱의 `--color-accent: #0b5497` 보다 **더 깊고 채도가 낮은 네이비**다 → 학교 색과의 연결이 약했던 것이 "투박" 인상의 한 원인.
- 보조 색은 **추가하지 않는다**(튀지 않게). 강조는 **네이비 1색 + 중성 3단계**로만 만든다.

- 대비 기준은 **기존과 동일하게 4.5:1 이상**을 유지한다(네이비 `#00347F` on white ≈ **11:1**).

### 2-1. v2 피드백 반영 — "좀 밝은 느낌" (2026-10-12)

> 사용자 피드백(그대로): "**좀 밝은느낌이면 좋을거같은데 왜케어둡지**"

**원인 3가지(실측)**: ① 브랜드 네이비 `#00347F` 를 **면·글자에 그대로** 써서 화면에 어두운 덩어리가 생김 ② 지난 시간 행을 `opacity .45` 로 눌러 화면 절반이 뿌옇게 가라앉음 ③ 중성 회색 텍스트(`#5B6672`)와 회색 배경(`#F7F8FA`)이 겹쳐 전체적으로 무거움. (+ 폰이 다크모드면 브라우저 자동 반전까지 겹칠 수 있음)

| 토큰 | v1 | **v2 (밝게)** | 이유 |
|---|---|---|---|
| `--brand`(면·글자) | `#00347F` | **`#1F62C7`** | 같은 계열에서 **명도만 올린 블루**(브랜드 인지 유지, 화면은 밝게) |
| `--brand-deep`(신규) | — | `#00347F` | 학교 네이비는 **작은 액센트(로고·점·바)** 에만 |
| `--brand-soft`(선택 칩) | `#E9EFF8` | **`#E8F1FE`** | 더 밝고 맑은 블루 톤 |
| `--brand-tint`("지금" 행) | `#EDF3FB` | **`#EDF5FF`** | 배경 대비만 살짝, 어둡지 않게 |
| `--bg` | `#F7F8FA` | **`#FBFCFE`** (B는 `#FFFFFF`) | 회색기 제거, 흰색에 가깝게 |
| `--text` | `#17202A` | `#1B2634` | 순흑 느낌 완화 |
| `--muted` / `--dim` | `#5B6672` / `#8A94A0` | `#66717F` / `#8C97A6` | 회색을 살짝 밝게(대비 4.5:1 유지) |
| 지난 시간 행 | `opacity .45` | **`opacity .60`** | 절반이 죽어 보이던 문제 완화 |
| 다크모드 대응 | 없음 | **`color-scheme: light` + meta** | 폰 다크모드에서 자동 반전되어 어둡게 보이는 것 방지 |

- 원칙은 그대로: **큰 면은 흰색/아주 옅은 블루, 진한 네이비는 점·바·작은 라벨에만.**


### 2-2. v3 — 로고 문양 색 + 카드 레이아웃 (2026-11-08, 적용됨)

> 사용자 피드백: "너무 밋밋하게 UI를 만들어놨어.. 간격이나 이런것들도 잘 안맞은 상태고" · "선문대학교 로고 문양의 색감으로 UI를 개선했으면 좋겠어"

- **로고 픽셀 실측**(`lily.sunmoon.ac.kr/images2/main/50th_logo_2.png`, 흰색·투명 제외 빈도순): 딥 틸 `#086070`/`#006878`(문양 주색) · 크림슨 `#C01840`/`#D01040`(문양 포인트) · 실버 `#A0A8B0`(워드마크). → 사이트 DOM 의 네이비 `#00347F` 는 로고 문양 색이 아니었다.
- 팔레트: `--color-accent #00687A`(틸, 표면 대비 6.4:1) · `--color-accent-soft #E3F1F3` · `--color-highlight #E6F3F4` · `--color-brand-deep #004B58`(다음 행 좌측 바) · `--color-brand-red #C81840`(`다음` 라벨·오늘 점에만) · 배경 `#F3F6F7`(실버 기운).
- 레이아웃: 시간표를 **흰 카드 1개**(radius 14 · 옅은 그림자)로 띄우고 행은 인셋 구분선만 · 시각 열 고정 폭(`--time-col`)으로 노선명 세로 정렬 · 노선명 15px/600 · 다음 행에 크림슨 `다음` 라벨 · 칩 알약 + 편수 배지 · 앱바 버튼 상자 테두리 제거 · 플로팅 버튼 그림자.
- 규격(15/13/11 폰트 · 앱바 52 · 요일 40 · 칩 34/44 · 행 56)은 그대로. 아이콘·manifest·privacy.css 색도 같은 토큰으로 맞췄다. **Android 자산·AAB 재동기화는 아직 안 함.**

## 3. "덜 딱딱하게, 그래도 안 튀게" — 원칙 5개

1. **상자 대신 여백·인셋선**: 행마다 테두리를 두르지 않는다. 노선 **그룹**만 부드러운 표면(radius 14px)으로 묶고, 그룹 안의 행은 **1px 인셋 구분선**(`#EFF2F6`)으로 나눈다.
2. **위계는 크기보다 무게·색으로**: 시각 `600`, 노선 `500`, 보조 `400`(muted). 폰트 크기는 사용자 지시대로 **15/13/11 유지**(더 키우지 않는다) — 크기 대신 **굵기·색·숫자 정렬(tabular-nums)** 로 스캔이 쉬워진다.
3. **강조는 1색, 면으로**: 선택 칩·탭 = **네이비 8% 면 + 네이비 글자**(테두리 굵게 하지 않음) · "지금" 행 = **네이비 6% 배경 + 좌측 3px 바** + 작은 `다음` 라벨.
4. **모서리는 전부 둥글게, 그림자는 최소**: 칩 알약(999), 그룹 14px, 시트 20px. 그림자는 플로팅 버튼·시트에만.
5. **움직임은 짧고 조용하게**: 150~200ms ease-out · hover 는 배경 톤만 · `prefers-reduced-motion` 유지.

**금지**: 그라디언트 남용, 노선별 색 구분(색이 많아지면 튄다), 이모지·일러스트 추가, 유료 폰트/킷, 그림자 다중 레이어.

## 4. 시안 3종 (비교용 목업)

| 시안 | 성격 | 강점 | 약점 |
|---|---|---|---|
| **A. Soft Cards** | 노선별 **부드러운 카드** 그룹 | 그룹 경계가 명확, 가장 "부드러워" 보임 | 카드가 많아 화면이 조금 길어짐 |
| **B. Quiet List** | 카드 없이 **인셋선 + 타이포 위계** | 가장 차분·깔끔, 정보 밀도 높음 | 색이 거의 없어 호불호 |
| **C. Tinted Focus** | 평면 목록 + **"지금" 행만 색면 강조** | 지금 탈 편이 즉시 눈에 들어옴 | 강조가 한 곳에만 있어 단조로울 수 있음 |

## 5. 적용 범위 (시안 확정 후 구현 태스크)

1. `tokens.css` 팔레트·반지름 교체(위 표) — **컴포넌트 수정 전에 토큰만 먼저**
2. `app.css` 의 행/그룹/칩/탭 규칙 교체(상자 → 인셋선, 알약, 면 강조)
3. "지금" 행 강조 스타일(배경 + 좌측 바 + `다음` 라벨) — 판정 로직은 그대로(`tripStatus` 재사용)
4. 스모크 갱신: 대비 실측(4.5:1) · 터치(칩 44/행 48) · 가로 스크롤 0 · `전체` 0건 · 섞임 0건 유지
5. **AAB 재빌드 + Android 자산 재동기화**(§14-2) — 웹만 바꾸면 앱이 옛 화면이 된다
