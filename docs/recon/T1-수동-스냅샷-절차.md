> **원칙: 자동 크롤 금지.** `robots.txt` 가 `Disallow: /Page`(접두사)로 `/Page2/...` 를 포함 차단한다.
> 따라서 자동 수집 파이프라인을 기본 경로로 삼지 않고, **사람이 브라우저로 저장 → 저장소 커밋 → 파서가 정규화** 한다.
> (학교 이용 허락을 받기 전에는 자동 수집을 하지 않는다 — `docs/01 §8`.)

## 2. 저장 형식

1. **1순위 — HTML 완전 저장(권장)**
   브라우저에서 페이지를 연 뒤 `다른 이름으로 저장` → 형식 **`웹페이지, HTML만`**(`*.html`).
   - 이유: 파서가 `<table>`/`colspan` 구조를 그대로 읽는다. 저장된 HTML이 곧 골든 픽스처·증거가 된다.
   - 저장 전 새로고침(F5)으로 최신본을 받고, 완전히 로드된 뒤 저장한다.
   - 파일 크기 기준(실측): 평일 페이지 약 **100~133KB** → 11개 합계 약 **1.3MB**(저장소 부담 없음).
2. **2순위(대안) — 인쇄 → PDF로 저장** (`*.pdf`, 확장자만 `pdf` 로)
   - HTML 저장이 어려운 환경(모바일·태블릿)에서만 사용. **파서가 PDF 텍스트를 추출할 수 있어야 하므로 T2 지원 범위 확인 필요**(현 파서 계약은 HTML 기준).
   - PDF일 때는 열 병합·줄바꿈이 뭉개질 수 있어 §5 검증 체크리스트를 더 엄격히 본다.
3. 저장 직후 **주소창 URL을 메모**한다(§1 표의 URL과 대조 → "이 파일이 어느 노선·요일인지" 증거).
4. 저장 파일은 그대로 `data/raw/` 에 넣는다(가공·편집 금지 — 원본 증거).

## 3. 파일명 규칙

```
data/raw/<학기>-<노선>-<요일>[-<저장일>].html
```

| 토큰 | 값 | 규칙 |
|---|---|---|
| `<학기>` | `2026-2학기` | 원본 페이지 표기 그대로(학기 바뀌면 그 값) |
| `<노선>` | `아산KTX` `천안역` `천안터미널` `온양역터미널` `천안캠퍼스` | 파일명 금지문자(`/` 등) 제거 — 원본 노선명 `온양역/터미널` → `온양역터미널` |
| `<요일>` | `평일` `토요일` `일요일` | 원본 탭 라벨 그대로 |
| `[-<저장일>]` | `YYYYMMDD` (예: `20261005`) | **생략 가능하지만 포함을 권장** — 같은 학기에 재저장할 때 이력 구분 |

- 확장자: HTML 저장본은 `.html`, 인쇄 대안은 `.pdf`.
- URL 의 `About08_04_02_01_01_02` 같은 코드는 **파일명에 쓰지 않는다**(사람이 읽는 규칙 우선). URL↔파일 매핑은 이 문서 §1 표가 정본.
- 이름에 공백·`()`·`/`·`"` 를 쓰지 않는다(예: `아산(KTX)역` → `아산KTX`).
- ⚠️ **현재 커밋된 스냅샷 5개**(`data/raw/2026-2학기-<노선>-요일혼합.html`, 커밋 `e9d1184`)는 파일명과 달리 **내용은 전부 "평일" 페이지만** 담고 있다(실측: `.btn_tab act` 가 평일 탭 = `tablist10`~`tablist14`). 규칙대로면 `-평일-<저장일>` 이며, **토요일·일요일 5개 페이지는 아직 없다**(§1 표). 파일 개명·추가 반입 여부는 `data/raw` 소관(T2/총괄) 판단이며 이 워커는 파일을 건드리지 않았다.

## 4. 저장 후 실행할 명령

```bash
npm ci                       # 1) 의존성 설치 (package-lock 기준 · Node ≥ 26)
npm run scrape               # 2) data/raw/*.html → data/timetable.json  (현재는 자리표시자 exit 1 · T2가 구현)
npm run test                 # 3) 골든 픽스처 대조(AC-1) + 결정성(AC-2)
npm run lint:boundary        # (선택) 헥사고날 경계 검사 — src/domain 순수성 등
```

- `npm run scrape` 는 T0 골격(태스크 `t_37cdfc3e`, 커밋 `4f6980d`)에서 **이름이 고정**됐다(실행: `tsx tools/scraper/index.ts`). 지금 실행하면 미구현 메시지와 함께 `exit 1` 이며 **T2가 이 파일을 대체**한다.
- `npm run scrape -- --local` 은 `docs/01 §8`·T1 태스크에 적힌 **예정 인터페이스**(네트워크 없이 `data/raw/` 만 읽는 모드)이며 **T2 구현 시 확정**된다.
- 스냅샷 파일명·URL 매핑이 §1·§3에 고정돼 있으므로 `--local` 모드는 요일·노선을 **파일명에서 해석**하면 된다.
- 파서가 실패하면(행 수·헤더 불일치) **마지막 정상 `data/timetable.json` 을 유지**한다(F8). 앱은 빈 화면이 아니라 직전 데이터 + 경고를 보여준다.

## 5. 스냅샷 검증 체크리스트 (사람이 저장 직후 확인)

## 6. 스냅샷이 오래되면 앱에 표시할 문구 (제안 — 확정은 T5/총괄)

스냅샷 방식은 "수집이 자동으로 신선해지지 않는다"는 사실을 사용자에게 정직하게 알려야 한다.

- 기준: `data/timetable.json` 의 `source.fetchedAt`(전역 수집 시각)과 노선별 `sourceUpdatedAt` 을 그대로 노출.
- 화면 문구(예시)
  - 신선: `시간표 기준 2026-2학기 · 원본 최근 업데이트 2026-08-20`
  - 24시간 초과: `마지막 반영: 2026-10-05 · 원본 페이지에서 최신 여부를 확인하세요`
  - 학기 개편 의심(골든 불일치로 파서 실패): `원본 시간표가 개편된 것으로 보입니다. 마지막 정상 데이터(YYYY-MM-DD)를 표시합니다.` + 원본 링크
- 노선별 `최근 업데이트` 값이 서로 다르므로 **노선 화면에서 각 노선의 값**을 보여주는 편이 정확하다(단일 전역 값으로 뭉치면 실제보다 최신처럼 보일 수 있다).
- 문구 확정·다국어(한/영)·접근성은 T5(UI) 소관 — 이 문서는 재료만 제공한다.

## 7. 이번 T1에서 실제로 한 요청 (감사 기록)

- 총 **6건**: `/robots.txt` 1건 + 노선 페이지 5건(평일 4 + 아산KTX 토요일 1).
- 조건: `User-Agent` 명시(Chrome/131), 요청 간 2초, 1회성. **자동화 파이프라인 없음.**
- 아산KTX 평일 페이지는 총괄이 이미 받아둔 캐시를 사용하고 **재요청하지 않았다.**
- 결과: 전부 HTTP 200(차단 없음). 원본 스냅샷은 개인 캐시에만 보관, 레포에는 커밋하지 않았다.
- 총괄이 **같은 시각에 1회 반입한 `data/raw/*.html`**(커밋 `e9d1184`, 5개 노선)와 내가 받은 4개 페이지는 **`__VIEWSTATE`/`__EVENTVALIDATION` 동적 토큰만 다르고 나머지는 완전 동일**했다(마스킹 후 sha256 일치) — 같은 페이지를 각자 1회씩 받은 결과이며, 이후 중복 요청은 하지 않았다.
