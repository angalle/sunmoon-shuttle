## 4. 표가 여러 개인 이유 — 각 표의 역할 [실측]

천안역/터미널/온양/아산KTX 평일 페이지는 `<table>` 이 **3개** 나오지만 시간표는 하나뿐이다.

| 순서 | 마크업 | 역할 |
|---|---|---|
| 1 | `<div class="table_type2 mgT30"> <!------------------시간표시작-------------------> <table></table>` | **빈 표(내용 0행)** — 레이아웃/자리표시용. **파서는 무시해야 한다** |
| 2 | `<table><thead><tr><th>순</th>…` | **본표**(시간표 본문) |
| 3 | `<table style="margin-top:20px;height:35px;width:100%;maxwidth:800px;">` (1행 2열) | **안내표** — 내용은 `학생회관 승차 가능 시간, 이외 시간은 공대 승강장에서만 승차가능합니다.` (시간표 아님) |

- 본문 컨테이너 구조(천안역 원본, 태그 오프셋 실측): `<!-- 학기 시간표 -->` → `<div id="tabcontent1">`(요일·노선 탭 네비) → `<div id="tabcontent22">` → `<h4 class="title22">○  천안역</h4>` + `<div class="grayBox mgT30">`(운행노선·소요시간) → `<div class="table_type2 mgT30">`(빈 표 + 본표) → `<!------------------시간표끝------------------->` → 안내표 → `○ 노선별 시내버스 참고` / `○ 안내사항` → `<!-- // 방학 시간표 -->`
- 아산KTX 평일 캐시(markdown)에서도 같은 자리에 빈 표가 나타난다(캐시의 "표 3개" 서술과 일치) [총괄캐시] — 커밋 픽스처 `data/raw/2026-2학기-asan-ktx-요일혼합.html` 파싱 결과도 **동일**(표 3개 = 빈 표 + 본표 43행 + 안내표 1행) [실측]
- 상단 `.tabcontent > div` hide/show JS(`#tab201~#tab204`, `$('.tabnav a').click(...)`)는 **상단 메뉴 탭**용이며 요일 전환과 무관하다.

### 9.2 스키마 확장이 필요한 사실 (판단·확정은 총괄)
1. **노선 × 요일 매트릭스가 비대칭**: 평일 5 / 토 3 / 일 3. `routes[].byDay` 구조로 토·일에 없는 노선(온양·천안캠퍼스)을 어떻게 표현할지(빈 배열 vs 키 생략) 확정 필요.
2. `routes[].columns` 가 노선·요일별로 다름(5/7/8/8 → 4열) → "노선별 columns 허용"을 문서에 명시해야 함.
3. `source.sourceUpdatedAt` 단일값 → **페이지(노선)별 값 필요**(2026-08-20 vs 2025-08-27 실측). 예: `routes[].sourceUpdatedAt` + 전역 `source.fetchedAt`.
4. `null`(운행 없음)만으로는 `금(X)·중간노선 전용·경유` 같은 값 구분이 안 됨 → `note`/별도 필드로 보존 필요.
5. **표 선택 규칙**(파서): `div.table_type2` 안의 **비어있지 않은 표 1개**가 본표. 빈 `<table></table>` 와 `table[style*="height:35px"]`(안내표)는 제외. `<thead>` 헤더행·토요일의 `<th colspan="4">` 제목행은 데이터가 아님.
6. `schemaVersion` 증가 여부: 위 1~4 중 채택되는 항목에 따라 결정(현재 1).
