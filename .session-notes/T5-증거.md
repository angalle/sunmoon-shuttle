## 6. 남은 한계 · 가정 (완료로 위장하지 않음)

1. **계약 해석 1건(가정)** — `depStation ← depStation ?? depTerminal`. 근거: 둘 다 "출발(역/터미널)" 열(`tools/scraper/routeMeta.ts` `kind:'time'`)이고 도메인 `tripDepartureTime = depCampus ?? depStation` 계약. T4 기록의 미해결 질문("천안역 열 수 … T2/T10 에서 열 매핑 확정 필요")에 대한 **T5 쪽 임시 정규화**이며, 정본이 다르게 확정되면 `data/normalize.ts` 한 파일만 고치면 된다.
2. **도메인 `Route` 타입이 외부 계약보다 좁다**(`status`·`suspendedReason`·`offDays`·가변 `columns` 없음) → 뷰모델이 별도 보존. 도메인에 반영되면 뷰모델에서 제거 가능.
3. **기간 안내문 전개** — `notices[]` 중 `endDate` 가 있는 항목(추석연휴 9.24~9.26)은 T4 계약대로 **하루 단위로 전개되지 않아** `resolveDayService` 는 시작일만 인식한다. 화면에는 원문 범위(`*추석연휴[9.24(목)~9.26(토)]…`)를 그대로 보여줘 오해는 없다. 전개는 T2 소관(잔여 불일치로 기록).
4. **컴포넌트 단위 DOM 테스트 없음** — 이번 실행에서는 `jsdom` 설치가 보안 정책으로 차단되어(`npm install` 차단), 원자·분자·유기체의 DOM 계약은 **`scripts/render_smoke.mjs`(실제 Chrome CDP)** 로 검증했다(탭 전환·키보드 이동·행 수·null 셀·오류 UI). 순수 로직(정규화·selectors·store·포맷)은 vitest 105건.
5. **오프라인 캐시 없음** — T6 소관. 이 카드에서는 "실패 시 빈 화면·크래시 금지"(오류 배너 + 원본 링크)까지만 구현. 새로고침 오프라인은 이전 데이터를 유지하지 않는다(캐시 계층 필요 — T6).
6. **다크 모드**는 토큰에 최소 정의(`prefers-color-scheme`)만 했고 토글·한/영은 T7 소관.
7. 배포·Pages 확인은 하지 않았다(infra 소관) — 하위 경로 시뮬레이션(`/sunmoon-shuttle/`)으로만 검증했고, 실 URL 확인은 총괄이 수행.
