
## 5. 미검증·한계 (정직 기록)

1. **API 31 미만 실기기/에뮬레이터 미검증** — 이 맥에는 API 35 AVD 하나뿐이다. `android:background=@drawable/splash`(layer-list)는 API<31 의 스플래시 경로인데, 그 경로를 실제로 렌더해 보지 못했다(리소스 컴파일·`aapt2 dump` 까지만 확인).
2. **다크 모드 프레임 미촬영** — `values-night`(색 `#12161B`, 상태바 아이콘 밝게)는 리소스 값으로만 확인(resources.arsc). 다크 화면 스크린샷은 없다.
3. 스크린샷 간격 ≈110ms — 그보다 짧은 전환은 못 잡는다.
4. Android 12+ 시스템 스플래시의 아이콘 크기·마스킹은 런처/기기 정책에 따라 달라질 수 있다(에뮬레이터 실측은 1종).
5. 서명은 **debug 키**(`android/keystore.properties` 없음) — 스토어 제출용이 아니다. 업로드 키 주입은 별도 승인 사항(비밀값은 문서·로그에 남기지 않음).
