## 남은 한계 · 주의 (완료라고 쓰지 않는다)

1. **옛 셸로 쓴 자산은 T25 빌드(Android 자산)** 다 — 저장소의 웹 `dist` 는 추적 대상이 아니라 과거 빌드가 남아 있지 않다. 사용자 기기에 캐시돼 있던 T30 시점 셸을 바이트로 복원할 수는 없으므로, **"설치 안내가 남아 있는 진짜 옛 번들"**(T25)로 같은 상태를 재현했다. 실제 사용자 기기는 별도로 **한 번 새로고침하면 새 셸로 바뀐다**(SW 가 즉시 교체 — skipWaiting/clients.claim).
2. **설치된 PWA(standalone)의 즉시 반영은 이 하네스가 측정하지 못한다.** 하네스는 일반 브라우저(모바일 에뮬레이션)에서 셸 교체만 실측했다. iOS 실기기(Safari·홈 화면 추가)는 머신에 없어 **사람 게이트**(`scripts/qa/iOS-CHECKLIST.md`)로 남는다.
3. `?now=` 운행일 검증은 **오늘(2026-10-09 한글날) 운행이 없어** 시각을 주입해 확인했다(빈 상태 자체는 정상 동작 — `T32-3` 스크린샷의 `오늘 셔틀버스 운행이 없습니다`).
4. **경로 한정 이탈 1건**: `index.html`(루트) 주석 문구 수정. 카드의 커밋 경로 목록에 없지만 AC-U14-3 의 `dist/**` 금지어 0건을 만족시키려면 원본이어야 해서 함께 고치고 커밋했다(변경은 주석 1줄 · 화면 동작 0).
