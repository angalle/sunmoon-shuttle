## 5. 발견(한계) — T35가 반드시 알아야 할 것

1. **colspan(병합 셀) 페이지에서 AI 초안이 어긋난다** — `tableRegion.ts` 는 셀을 **원문 순서대로**만 뽑아 `colspan` 을 논리 열로 확장하지 않는다(규칙 파서 `scraper/parse.ts` 는 확장한다).
   실측 예(`cheonan-terminal-평일` 1행): 규칙 `viaHomeMart="5분~20분 소요예상" · arrCampus="08:50"` ↔ AI `viaHomeMart="8:50" · arrCampus=null` → **0/38행 일치**.
   검증 4종은 이 어긋남을 **잡지 못한다**(값이 원문에 존재하고 시각 집합·행 수도 맞으므로 통과). 잡는 것은 행 단위 교차검증(§5)이다.
   → 권고: (a) `tableRegion.ts` 에 `colspan` 슬롯 확장을 넣는 **후속 수정**(규칙 파서와 같은 규칙), 그리고/또는 (b) T35 게이트가 "AI 불일치"만으로 매 실행 보류하지 않도록, **규칙이 행을 만든 페이지에서는 규칙 정본 발행을 정상 경로로 두고** 드리프트 신호(노선 소실·편수 ±10%·열 키 변경)로만 차단할 것.
2. **60초 API 타임아웃**: 가장 큰 표(`cheonan-station-평일`)는 `deepseek-v4-flash` 가 60초(`DEFAULT_API_TIMEOUT_MS`) 안에 응답하지 못해 폴백했다(치명 아님, 다음 실행에서 재시도·성공). 심야 배치에서는 재시도로 흡수되지만 반복되면 타임아웃 상향을 검토.
3. 모의 증거의 `agreedRows=78 / disagreedRows=70` 은 실 실행과 같은 값이다 — 모의 faithful 초안이 "원문 토큰 그대로"라 실 모델 초안과 같은 어긋남(병합 셀)을 갖기 때문이다.
