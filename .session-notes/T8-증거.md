## 4. 남은 위험·가정 (미검증)

1. **실기기 미검증** — API 35 에뮬레이터(swiftshader 소프트웨어 GPU)만 실측했다. 실기기 하드웨어 렌더링·다크 모드 첫 프레임 번쩍임(`backgroundColor` 정적 1색 한계)은 미검증.
2. **release AAB 실행 미검증** — AAB 는 서명·구조까지만 확인했고, 배포/설치 검증은 debug APK 로만 했다(debug 항목이 release 번들에도 있음은 `bundleRelease` 성공 + assets 동봉으로 확인).
3. **Play 업로드 미검증** — Play 계정 결제·등록은 카드 금지 범위라 하지 않았다. `jarsigner`/`apksigner` 상 signer 는 `CN=Android Debug` 이므로 **업로드 키 발급이 선행돼야 한다**.
4. **JDK 21/AGP 상향 미적용** — JDK 21 설치(무료)로 `subprojects` 패치와 compileSdk 경고를 없앨 수 있으나 시스템 변경이라 승인 대기.
5. **동시 작업 간섭** — `dist/` 와 `android/app/src/main/assets/public/` 은 생성물 공용 경로다. 같은 워크스페이스에서 `scripts/qa/ios_compat_check.mjs`(다른 워커)가 `dist/` 를 만지고 있었다 — 두 워커가 동시에 빌드하면 서로의 `dist` 를 지운다(`emptyOutDir`). 순차 실행을 권장한다.
