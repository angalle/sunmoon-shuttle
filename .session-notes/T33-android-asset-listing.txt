## 3) git 추적 여부 — **추적 대상이 아니다**(자산은 빌드 산출물)
    $ git check-ignore -v android/app/src/main/assets/public/index.html android/app/src/main/assets/public/sw.js
    android/.gitignore:96:app/src/main/assets/public	android/app/src/main/assets/public/index.html
    android/.gitignore:96:app/src/main/assets/public	android/app/src/main/assets/public/sw.js
    check-ignore exit=0

    $ git ls-files android/app/src/main/assets/public | wc -l
    0

→ android/.gitignore 96행 `app/src/main/assets/public` 로 **자산 전체가 ignore** 된다.
  즉 "새 번들·삭제된 옛 번들을 함께 커밋"은 **해당 없음**(커밋할 대상이 존재하지 않는다).
  자산은 `node scripts/sync-android-assets.mjs`(또는 `cap copy|sync android`)로 dist 에서 언제든 재생성된다.
  android/ 안에서 추적되는 것은 res/(아이콘·스플래시), build.gradle, AndroidManifest.xml, MainActivity.java 등 native 소스뿐이다.
