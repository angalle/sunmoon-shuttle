## 0. 한 줄 결론

`dist/` 최신 빌드(T32 이후)를 **스크립트로** Android 자산에 재동기화했고(멱등 · 옛 해시 번들 제거),
AAB/APK 를 재빌드해 **서명 검증 PASS**, 에뮬레이터에서 **설치 안내 0건 · 금지어 0건 · 운행일 시간표 115행 렌더 ·
logcat FATAL 0** 을 실측했다. 에뮬레이터의 **이전 설치본(옛 번들)에서는 설치 안내가 실제로 보였다**는
before/after 도 같은 기기에서 캡처했다.

## 2. 새 스크립트 (모두 `scripts/`)

| 파일 | 역할 |
|---|---|
| `scripts/sync-android-assets.mjs` | `dist/` → `android/app/src/main/assets/public/` 재동기화. 대상을 지우고 통째로 복사(Capacitor `copyWebDir` 와 같은 의미) → **옛 해시 번들은 남지 않는다**. `cordova.js`·`cordova_plugins.js`(Capacitor 자리표시자)만 보존. 파일 목록·내용의 sha256 manifest 를 전후로 계산해 `CHANGED` 를 보고(멱등 증명). `--check` 는 복사 없이 드리프트만 검사 |
| `scripts/t33_artifact_asset_check.sh` | AAB/APK **안**의 `assets/public` 을 풀어 ① 옛 번들 0 ② 금지어 0 ③ `SW_VERSION` == dist ④ 계약 데이터 동봉 ⑤ `jarsigner -verify` 를 검사 |
| `scripts/t33_webview_dom.mjs` | 에뮬레이터 WebView 에 CDP 로 붙어 **DOM 을 직접 평가**(설치 안내 노드·금지어·번들 이름·행 수·캐시 키). `--nav` 로 날짜 주입 |
| `scripts/t33_emulator_smoke.sh` | 에뮬 기동 → (가능하면) 이전 설치본 before 측정 → `install -r` → 1·2차 로드 DOM 측정 → 운행일 주입 측정 → logcat 판정 → 에뮬 종료 |

`android/README.md` 에 사용법·근거·추적 여부를 추가했다.

**Capacitor 와의 등가성**: `bash android/build-release.sh`(내부에서 `cap sync android`)를 돌린 **뒤**
`--check` 를 실행하면 `SYNC-CHECK IN-SYNC` · 대상 manifest `5fe341c366f046d7` 로 **같은 값**이 나온다
(`T33-sync-check-after-cap-sync.txt`). 즉 이 스크립트의 산출물 = Capacitor 가 만드는 산출물.

## 6. 자산 추적 여부 (AC-U14-3e)

`android/.gitignore:96` 이 `app/src/main/assets/public` 을 무시한다 → `git ls-files` 결과 **0개**.
즉 "새 번들·삭제된 옛 번들을 함께 커밋"은 **해당 없음**(커밋할 자산이 존재하지 않는다).
자산은 `node scripts/sync-android-assets.mjs` 한 줄로 언제든 dist 에서 재생성된다.

## 9. 남은 위험 · 가정 · 되돌리기

- **미검증**: ① 설치형 PWA(iOS/Android 홈 화면) 실기기 즉시 반영(사람 게이트 — 웹 쪽 T32 범위)
  ② API<31 스플래시 경로(T25 부터 미검증 · 이번 변경과 무관) ③ `?now=` 주입은 앱의 계약 경로지만,
  실제 사용자 기기의 시스템 시계 경로는 아니다(오늘 화면은 휴일 상태만 실측).
- **서명**: `android/keystore.properties` 가 없어 **debug 키** 서명이다 → **스토어 제출용 아님**(T25 와 동일).
- **versionCode 1 유지**: 이번은 로컬 재빌드므로 올리지 않았다. **Play 업로드 시 반드시 +1**
  (`android/app/build.gradle` · README 표).
- **가정**: `dist/` 가 이 태스크보다 앞선 T32 산출물이라는 것(번들 `index-403hrULs.js` · `SW_VERSION 2026-10-09.1`).
  `dist/` 는 gitignore 대상이라 저장소에 없다 — 다른 머신에서는 `npm run build` 후 sync 해야 같은 상태가 된다.
- **되돌리기**: 자산은 `git checkout` 대상이 아니다(추적 안 함). 되돌리려면 옛 커밋에서 `npm run build` 하거나
  `cap sync` 없이 `android/app/src/main/assets/public/` 을 삭제 후 `bash android/build-release.sh`.
  새 스크립트 4개와 README 문단은 `git revert <이 커밋>` 으로 제거(웹 소스·`public/**` 는 손대지 않았다).
- **경계 준수**: `src/**`·`public/**`·`tests/**` 는 수정하지 않았다(T32 담당). 커밋 범위는 `scripts/**` · `android/README.md` · `.session-notes/T33-*`.
