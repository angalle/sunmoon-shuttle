## 2. 결정성 (같은 스냅샷 → 같은 JSON)

```bash
bash .session-notes/evidence/t2-run.sh
===== A. DETERMINISM (3 runs, fetchedAt masked) =====
177a54fe7faed7a1f0a3ce76209b2c6e55be0343bf7fade507998cb53b0b2904  .../det1.masked.json
177a54fe7faed7a1f0a3ce76209b2c6e55be0343bf7fade507998cb53b0b2904  .../det2.masked.json
177a54fe7faed7a1f0a3ce76209b2c6e55be0343bf7fade507998cb53b0b2904  .../det3.masked.json
diff det1-det2: 0 lines (identical)

===== B. FIXED --now (byte-identical) =====
byte-identical: YES (df841c0762f287b1)
```

- `fetchedAt`(수집 시각)은 데이터가 아니므로 **마스킹 후 해시 비교**로 판정 → 3회 완전 동일.
- `--now <ISO8601>` 로 시각을 고정하면 **바이트 단위 완전 동일**(`cmp -s` 통과) — CI 비교용.
- 내부 `source.contentHash` 도 시각 독립(3회 마스킹 결과가 같으므로 확인됨).
