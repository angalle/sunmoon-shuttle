## 2. 자세한 설명

```
선문대학교 셔틀버스 시간표를 빠르게 확인하는 앱입니다.

■ 세 번만 고르면 끝
· 요일: 평일 / 토요일 / 일요일
· 정류장: 아산(KTX)역 · 천안역 · 천안터미널 · 온양역/터미널
· 방향: 시간표 머리를 누르면 "학교 → 역" ↔ "역 → 학교"가 바뀝니다

■ 표 하나로 출발·도착까지
· 출발 시각, 걸리는 시간(약 15분 등), 도착 시각을 한 줄에
· 다음에 올 버스를 바로 표시
· 금요일 휴무(금휴), 요일별 운행 같은 조건을 눈에 띄게 표시
· 중간 정류장에서 출발하는 편도 함께 보여 줍니다

■ 인터넷이 없어도
· 마지막으로 받은 시간표를 그대로 보여 줍니다
· 연결되면 알아서 최신 시간표로 바뀝니다

■ 편하게
· 마지막에 고른 요일·정류장·방향을 기억합니다
· 다크 모드 지원
· 운행 없는 날, 대체 시간표, 이용 안내를 한곳에서

■ 안내
· 이 앱은 선문대학교의 공식 앱이 아닌 비공식 앱입니다.
· 시간표는 학교 홈페이지에 공개된 셔틀버스 시간표를 옮겨 보여 줍니다. 실제 운행은 학교 공지와 다를 수 있으니 중요한 일정은 학교 공지를 함께 확인해 주세요.
· 회원가입·로그인이 없고, 개인정보를 수집하지 않습니다.
```

## 4. 앱 콘텐츠(정책) 답변

| 항목 | 답 |
|---|---|
| 개인정보처리방침 | https://angalle.github.io/sunmoon-shuttle/privacy.html |
| 앱 액세스 | 모든 기능을 특별한 액세스 권한 없이 사용 가능 |
| 광고 | 광고 없음 |
| 콘텐츠 등급 | 카테고리 "기타 앱"(참고·뉴스·교육 아님) → 폭력·성·언어·약물·도박 모두 **아니요**, 사용자 간 소통·콘텐츠 공유 **아니요**, 위치 공유 **아니요**, 디지털 구매 **아니요** → 전체이용가 |
| 타겟층 | 18세 이상 (대학생 대상 · 아동 대상 아님) |
| 뉴스 앱 | 아니요 |
| 데이터 보안 | 사용자 데이터 **수집 안 함** · **공유 안 함** (전송 암호화: 예 — HTTPS) |
| 광고 ID | 사용 안 함 (권한은 INTERNET 뿐) |
| 정부 앱 · 금융 기능 · 건강 | 해당 없음 |

데이터 보안 근거: 회원가입·로그인·위치·기기 ID·분석 도구 없음. 앱이 네트워크로 받는 것은 공개 시간표 JSON 뿐이고 요청에 이용자 정보를 담지 않는다. 화면 설정은 기기 안(localStorage)에만 저장된다 — `public/privacy.html` §1~3.

## 5. 그래픽 다시 만들기

- 아이콘: `node -e "import('./scripts/generate_icons.mjs').then(m=>require('fs').writeFileSync('store/play/icon-512.png', m.encodePng(512, m.renderIcon(512,{full:true,glyphScale:1,radiusRatio:0}))))"`
- 대표 이미지: `store/play/src/feature.html` 을 Chrome headless 로 1024×500 캡처
- 스크린샷: iOS 시뮬레이터(iPhone 17 Pro) 홈 화면 웹앱을 캡처 → 9:16(1206×2144)으로 자름
