# 원본 스냅샷 (data/raw)

이 디렉터리의 HTML 은 **원본 페이지를 운영자가 1회 저장한 스냅샷**이다(파서의 골든 픽스처·증거).

- 출처: `https://lily.sunmoon.ac.kr/Page2/About/About08_04_02_01_0*.aspx` (선문대학교 셔틀버스 안내)
- 수집 시각: 2026-10-05 (KST) · **1회 반입** · User-Agent 명시 · 요청 간 2초
- **자동 크롤 없음**: 원본 `robots.txt` 가 `Disallow: /Page`(= `/Page2/…` 포함)로 차단하므로 **정기 수집을 하지 않는다**(`docs/01-architecture.md §8`).
  정본 절차 = 사람이 브라우저로 저장 → 이 디렉터리에 커밋 → `npm run scrape -- --local` 로 JSON 생성.
- 파일명 규칙: `<학기>-<노선>-<요일>.html` (요일 탭이 서버렌더로 분리 불가하면 `요일혼합`)
- **변조 금지**: 이 파일이 파서의 기준이다(가공·정규화 금지).

- **2026-10-05**: 초기 반입한 5개 파일명이 `-요일혼합` 이었으나 **내용은 평일 탭 전용**이었다(T1 재조사에서 적발 — 총괄 파일명 오류). → `-평일` 로 **정정**하고, 토·일 **6개를 추가 반입**했다. 위 §"자동 크롤 없음" 원칙 아래 1회성으로 수행했다.
