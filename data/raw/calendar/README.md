# 학사력(학사일정) 원본 — 학년도마다 1회 반입

근거: `docs/10-academic-calendar.md` §4(안 B) · T41.

## 원본
- 학교 홈 → SM Story → 캘린더 → **`학사일정 다운로드`**
- 파일 주소: `https://lily.sunmoon.ac.kr/Download.aspx?file=/haksa/학사력.hwp` (HWP · 1년치 = 그 학년도 3월 ~ 다음 해 2월)
- 캘린더 **페이지**(`/Page2/...`)는 `robots.txt` 가 금지하는 경로라 월별로 긁지 않는다. 연간 파일 1개만 받는다.

## 반입 절차
1. 파일을 내려받아 이 폴더에 **`<학년도>학년도-학사력.hwp`** 로 둔다(예: `2027학년도-학사력.hwp`).
2. 텍스트 정본을 만든다(`uv` 필요 — pyhwp 를 일회성으로 실행하므로 저장소 의존성은 늘지 않는다):
   ```bash
   bash scripts/calendar_hwp_to_txt.sh data/raw/calendar/2027학년도-학사력.hwp
   ```
3. `.hwp` 와 `.txt` 를 **함께 커밋**한다. 파서는 `.txt` 만 읽는다. 같은 hwp 면 같은 txt 가 나온다(결정적).
4. 학교가 학년도 중에 일정을 고치면 같은 이름으로 다시 받아 2~3 을 반복한다 — `.txt` diff 로 무엇이 바뀌었는지 보인다.

## 언제
- **매년 2월 무렵** 다음 학년도 학사력이 올라오면 반입한다. 이게 있어야 **동계방학의 끝(다음 학년도 개강 전날)** 이 정해진다.
