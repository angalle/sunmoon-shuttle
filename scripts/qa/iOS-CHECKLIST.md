# iOS 경로 사람 체크리스트 (T9 · docs/03 AC-7)

작성: **AppDev-QA** · 2026-10-05 · **v1.0.0 개정 2026-11-14** · 대상: 배포본(v1.0.0 → v1.0.1)
배포본: https://angalle.github.io/sunmoon-shuttle/ (Pages 하위 경로 · CDN 캐시 최대 10분 → 배포 직후엔 새로고침 1회)

> **판정은 총괄이 한다.** 이 문서는 "자동화가 불가능한 항목"을 사람이 실기기에서 확인하기 위한 절차·기대값 목록이다.
> 자동 검증(아래 도구 3종)은 기계 판정 가능한 계약만 다루고, **아래 항목을 통과로 간주하지 않는다.**

## 0. 이 체크리스트가 필요한 이유 (한계 명시)

- 이 머신에는 **iOS 시뮬레이터·Xcode 전체가 없다**(`docs/00 §7` 실측 · CLT 만 설치). Safari/WebKit 엔진으로 이 앱을 띄울 수단이 없다.
- 따라서 T9 의 자동 도구는 **Chrome(Blink) 을 iPhone 뷰포트·iPhone UA·standalone 모드로 태워** 기계 검증 가능한 부분만 실측한다.
  Blink 로 확인한 "manifest 파싱·SW 등록·오프라인·safe-area 토큰 배선"은 계약의 **필요조건**이지 WebKit 실동작의 증명이 아니다.
- 홈 화면 추가·아이콘 렌더·전체화면 크롬은 **OS UI 조작**이라 헤드리스 브라우저에 존재하지 않는다(원리적으로 자동화 불가).

## 2. 사람 체크리스트 — v1.0.0 (2026-11-14 개정)

> 10월 판의 설치 안내 배너·다음 버스 카드·카운트다운·오프라인 안내 문구는 v1 에서 **삭제된 기능**이라 항목에서 뺐다.
> v1 화면: 요일 탭 · 정류장 칩(4곳) · 시간표 머리 `학교 (→) 아산(KTX)역`(한 줄 전체가 방향 바꾸기 버튼) · 표(출발 · 소요 · 도착).
> 자동 도구(§1)는 v1 화면으로 다시 돌려 통과했다(2026-11-14: 호환 44/44 · PWA 스모크 PASS · 자체검증 13/13).

준비: iPhone Safari 로 **https://angalle.github.io/sunmoon-shuttle/** 접속(배포 직후면 한 번 새로고침).

### A. 홈 화면 추가 · 전체화면
| # | 절차 | 기대값 |
|---|---|---|
| A1 | 공유 버튼 → **홈 화면에 추가** | 메뉴에 있다 · 이름이 `셔틀버스`(또는 manifest short_name) |
| A2 | 홈 화면 아이콘 확인 | 회색 사각형·스크린샷이 아니라 **틸색 버스 아이콘** |
| A3 | 아이콘으로 실행 | 주소창 없는 **전체화면** · 시작 화면이 약 1.4초 보였다 사라진다 |

### B. 화면 배치 (노치 · 홈 인디케이터)
| # | 절차 | 기대값 |
|---|---|---|
| B1 | 세로 화면 위·아래 확인 | 날짜·탭이 노치/다이내믹 아일랜드에, 마지막 행·오른쪽 아래 버튼이 홈 인디케이터에 **가리지 않는다** |
| B2 | 시간표 끝까지 스크롤 | 표가 시간표 머리 아래로 지나가고 머리는 그 자리 · 바닥 여백 깨짐 없음 |
| B3 | 가로로 돌려 보기 | 화면이 깨지지 않는다 · 글자가 갑자기 커지지 않는다 |

### C. v1 기능
| # | 절차 | 기대값 |
|---|---|---|
| C1 | 정류장 칩(천안역 등)을 차례로 누르기 | 시간표가 그 정류장 것으로 바뀐다 · 칩이 많으면 그 줄만 옆으로 넘어간다(화면 전체는 안 흔들림) |
| C2 | 시간표 머리 `학교 (→) 천안역` **아무 곳이나** 누르기 | `천안역 (→) 학교` 로 바뀌고 화살표가 반 바퀴 돈다 · 표가 반대 방향 시간표로 바뀐다 |
| C3 | 표 한 줄 읽기 | 왼쪽 = 출발지 출발 시각, 가운데 = 소요(`약 20분`)·`금휴`(노란 알약)·`다음`(빨간 알약), 오른쪽 = 도착 시각 |
| C4 | 오른쪽 아래 시계 버튼 | 오늘 요일로 돌아가고 다음 출발 줄로 이동 |
| C5 | 요일·정류장·방향을 바꾼 뒤 앱을 완전히 닫고 다시 열기 | **마지막에 고른 그대로** 열린다(날이 바뀌어도) |
| C6 | ⓘ 이용 안내 열기 → X 로 닫기 | 운행 없는 날·이용 안내·최신 데이터 시각이 보인다 · X 로 닫힌다 |

### D. 오프라인 · 자동 갱신
| # | 절차 | 기대값 |
|---|---|---|
| D1 | 한 번 정상 실행 → 비행기 모드 ON → 앱 완전 종료 후 실행 | **안내 문구 없이** 마지막 시간표가 뜬다(빈 화면·오류 없음) |
| D2 | 비행기 모드인 채로 요일·정류장·방향 바꾸기 | 즉시 바뀐다 |
| D3 | 앱을 켠 채로 비행기 모드 OFF → 1분쯤 기다리기 | 앱을 다시 열지 않아도 최신 데이터로 바뀐다(ⓘ 의 데이터 시각이 갱신) |

### E. 다크 모드 · 접근성 · 특이 환경
| # | 절차 | 기대값 |
|---|---|---|
| E1 | 설정 → 디스플레이 → 다크 모드 | 어두운 화면으로 바뀌고 글자가 잘 읽힌다 |
| E2 | VoiceOver 켜고 시간표 머리 · 정류장 칩 탐색 | 머리를 `방향 바꾸기 — 천안역 → 학교, 누르면 학교 → 천안역` 처럼 읽는다 · 칩은 눌림 상태를 읽는다 |
| E3 | Safari **개인정보 보호 브라우징**으로 접속 | 정상 표시(저장이 막혀도 동작) |
| E4 | 저전력 모드에서 실행 | 정상 표시 |
